# Graduate-School-Thesis
# Evaluating the Performance of Machine Learning Models in Predicting Seasonal and Extreme Rainfall in the Northern Part of Rwanda

## 1. Project Overview

This research evaluates the performance of machine learning models in predicting seasonal and extreme rainfall in the northern part of Rwanda. The study aims to explore rainfall patterns, identify rainfall variability and extreme rainfall events, and assess the predictive capabilities of selected machine learning algorithms.

The research uses historical rainfall data obtained from Meteo Rwanda and applies supervised machine learning techniques to classify rainfall patterns and distinguish extreme from non-extreme rainfall conditions.

## 2. Research Objectives

The study aims to:

- Analyze historical rainfall patterns in Northern Rwanda.
- Examine seasonal rainfall variability and characterize extreme rainfall events.
- Develop machine learning models for seasonal and extreme rainfall prediction.
- Evaluate and compare the predictive performance of selected machine learning algorithms.
- Identify the model that demonstrates the most effective performance based on selected evaluation metrics.

## 3. Study Area

The study focuses on the northern part of Rwanda, a region characterized by varying topography, climatic conditions, and rainfall patterns. Understanding rainfall variability in this region is important for agriculture, disaster risk reduction, water resource management, and climate resilience.

## 4. Data Source

The historical rainfall dataset used in this study was obtained from **Meteo Rwanda**.

The dataset is subjected to data cleaning, preprocessing, exploratory data analysis, feature engineering, and transformation to prepare it for machine learning model development.

## 5. Machine Learning Models

The study evaluates the following machine learning algorithms:

- **Random Forest (RF):** An ensemble learning algorithm that combines multiple decision trees to improve prediction performance and robustness.
- **Support Vector Machine (SVM):** A supervised learning algorithm that identifies decision boundaries between classes. This study uses the Radial Basis Function (RBF) kernel to model nonlinear relationships.
- **Logistic Regression (LR):** A statistical learning algorithm used for classification by estimating the probability of observations belonging to different classes.

## 6. Methodology

The research workflow consists of the following stages:

1. Data collection and inspection.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Feature engineering and feature selection.
5. Rainfall classification and event characterization.
6. Chronological data splitting and model validation.
7. Model training and hyperparameter tuning.
8. Model evaluation and comparison.
9. Interpretation and discussion of findings.

## 7. Model Evaluation Metrics

The predictive performance of the models is evaluated using the following metrics:

- Accuracy
- Precision
- Recall
- F1-score
- Receiver Operating Characteristic (ROC) and Area Under the Curve (AUC), where applicable
- Average Precision (AP), where applicable
- Confusion Matrix

These metrics are used to assess overall classification performance and the models' ability to correctly identify rainfall categories, particularly extreme rainfall events.
